# agentenv-portsim-plugin

[PortSimEnv](https://huggingface.co/spaces/FineEnvs/simulation-rl-environments), by Adithya S Kolavi at Hugging Face, as an
[AgentEnv Framework](https://github.com/scaleapi/agentenv-framework) plugin: an agent re-plans a disrupted week of
container-ship berthing at a Port of Barcelona quay, built from the port's real 2024 records, and is graded against a
re-plan CP-SAT proved optimal.

Work in progress.
